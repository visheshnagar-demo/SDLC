# Project Features

## SCRUM-256 - Email Classification System: Email Input, AI Categorization, and Review Dashboard

### Feature Summary
An intelligent Email Classification System that enables users to input email text or upload email files, automatically categorizes them using AI into Work, Personal, Urgent, or Promotional categories, and offers an intuitive dashboard to review, filter, search, and manually update classification results.

### Key Features
- Text area input and file upload (.eml, .txt, .pdf)
- AI-powered categorization engine with confidence scoring
- Interactive review dashboard with category tags and metadata
- Category override capability for users
- Filtering by category, confidence score, and date range
- Search functionality across email subjects and content
