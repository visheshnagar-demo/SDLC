# Project Features

## SCRUM-353 - Email Ingestion, AI Categorization & Review Dashboard

### Feature Summary
Allows business users to upload or paste emails for automatic AI classification into categories (Work, Personal, Urgent, Promotional) and review/edit the classifications via an interactive dashboard.

### Key Features
- Email Text Entry & File Ingestion (.eml, .msg, .txt up to 10MB)
- AI-Powered Email Categorization Engine (Work, Personal, Urgent, Promotional with confidence scores)
- Interactive Review & Manual Override Dashboard
