# Project Features

## SCRUM-319 - Simple Todo List Application

### Feature Summary
This feature provides a web-based Todo List interface where users can manage daily tasks, mark items as complete, filter tasks by status, and search tasks.

### Key Features
- Task Creation with title and optional description
- Task Viewing and List Display sorted by creation date/status
- Toggle Task Completion status
- Task Deletion
- Filtering tasks by status (All, Active, Completed) and search by keyword
