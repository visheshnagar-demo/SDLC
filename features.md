# Project Features

## SCRUM-282 - Unisex Gym Website: User Management, Membership Plans, and Class Scheduling

### Feature Summary
Allows unisex gym members and visitors to view membership tiers, browse class schedules, book workout sessions, and manage user profile and subscription details online.

### Key Features
- User Registration & Profile Management
- Membership Plan Selection & Management
- Class Schedule Browsing & Booking
- Admin Dashboard for Class and Member Management
