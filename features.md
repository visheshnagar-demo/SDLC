# Project Features

## SCRUM-279 - DG Cluster Assortment Advisor Dashboard

### Feature Summary
A single-page decision-support dashboard for Dollar General category managers to evaluate Snacks product assortment performance, select optimization scenarios (Conservative, Balanced, Aggressive), view guardrail checks, and submit assortment changes with inline audit-trail confirmations.

### Key Features
- KPI Header Strip: Top row displaying sales per linear ft, private brand %, in-stock rate, and shelf capacity cards.
- SKU Performance Table: Table listing Snacks SKUs with performance metrics and actionable status badges (GROW / MAINTAIN / SWAP / REDUCE).
- Scenario Selector: Three side-by-side selectable scenario cards (Conservative / Balanced / Aggressive) with Balanced pre-selected.
- Approval Review Panel: Real-time summary reflecting active scenario, SKU action breakdown, guardrail checks, and Submit button.
- Inline Confirmation: Success confirmation banner/modal showing audit-trail summary without page navigation.
