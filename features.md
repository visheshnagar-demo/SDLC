# Project Features

## SCRUM-320 - Ganesh Temple Management System

### Feature Summary
A full-stack web application allowing temple staff and devotees to register devotees, book poojas and archanas, make digital donations (e-Hundi), track temple inventory, and generate financial audit reports.

### Key Features
- Devotee & Membership Management
- Pooja & Archana Booking System
- Donation & E-Hundi Management
- Inventory & Seva Asset Tracking
- Financial Accounting & Audit Reporting
